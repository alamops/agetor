## 1. What we know

### 1.1 The model (Google sources, all read 2026-10-14)

- **Id and status.** `gemini-4-argon` is the only published code — stable, no `-preview` suffix, no `-latest` alias, no variants. Model page: ai.google.dev/gemini-api/docs/models/gemini-4-argon ("Stable: `gemini-4-argon`", last updated 2026-10-13). Changelog entry 2026-10-13: "Gemini 4 Argon (`gemini-4-argon`) generally available (GA) — our most capable model built for complex coding, agentic, math, and science tasks." Launch post (blog.google, 2026-10-13, Koray Kavukcuoglu) calls it "our latest frontier model" and says "the rest of the Gemini 4 family" is still to come — there is **no `gemini-4-pro`, `gemini-4-flash` or Argon-Cyber id**; the Fairwind no-guardrails access announced 2026-09-30 is the same model without a public code (contrast the `gemini-3.8-flash-cyber` row agetor carries on a convention-based id).
- **Thinking.** `thinking_level` ∈ `low | medium | high`, **default `medium`** (ai.google.dev/gemini-api/docs/latest-model table; thinking docs). No `minimal`, no documented `thinking_budget`, no off switch. `temperature`/`top_p`/`top_k` are ignored if sent. Context 1,048,576 tokens shared by input+thinking+output; max output 65,536 by default, up to 1,048,576 via background "long decode"; explicit caching unsupported. "Gemini 4 Argon can spend more of the limit on thinking than earlier models."
- **Pricing / tiers.** $2 in / $10 out / $0.10 cached per MTok through 2026-11-30, then $4 / $20 / $0.20 from 2026-12-01 (thinking billed as output; batch/flex half, priority 1.8×). **Not available on the API Free tier or the Google AI Pro plan.** Gemini app: AI Pro + Ultra. Antigravity: **AI Ultra subscribers** and "eligible Gemini Enterprise subscriptions" (antigravity.google blog, 2026-10-13). Vertex/Agent Platform serves it from the `global` location only (`us-central1` 404 — reported by the gemini-cli PR author below).
- **Neighbours.** Deprecations page (updated 2026-10-12): nothing names Argon as a replacement; `gemini-3.1-pro-preview` and `gemini-3.8-flash` have no shutdown date; `gemini-3.7-flash` was deprecated 2026-10-08 (auto-routed to 3.8, no longer selectable in AI Studio) and `gemini-3.5-flash` likewise → 3.6; the 2.5 models are access-limited to prior users since 2026-09-18 but "not deprecated". Three of agetor's seven gemini rows are therefore deprecated-or-restricted upstream today (pre-existing, not caused by this change).

## 3. What we're assuming

- **A1 — Gemini CLI passthrough is enough to ship.** `gemini -m gemini-4-argon` on 0.64.0 reaches the backend unchanged and runs at API-default `medium` thinking. If the backend rejects unregistered ids for the owner's auth mode (Code Assist OAuth tiers are unconfirmed for Argon), the plan must add a `MODEL_MIN_CLI_VERSION.gemini["gemini-4-argon"]` floor once a gemini-cli release ships PR #29737 (pre-flight 1b in `orchestrator.ts` already generalizes per kind) and word the row hint accordingly.
- **A2 — Antigravity's Argon ids follow its existing convention** (`gemini-4-argon-{high,medium,low}`). If wrong, curated rows are dead ids that fail at `agy` launch, while discovery still surfaces the real ones — so curated antigravity rows are a labelling convenience with a correctness risk, not a prerequisite.
- **A3 — Argon is the new gemini flagship and the default candidate** under the root rule "always default to the best available model" (as 3.1 Pro preview was). If the owner keeps 3.1 Pro preview as default, only placement/hints change and no README/test default pins move.
- **A4 — Cursor's unsuffixed label maps to the `high` variant** (house convention since 3.6 Flash; Cursor's own listing calls it "Gemini 4 Argon High").
- **A5 — fx row is `catalogOnly`** (signed-in presence unverified, same as every premium row since 2026-09-02).
- **A6 — No sibling Gemini 4 ids exist yet**; the plan must not invent `gemini-4-pro`/`-flash`/`-cyber` rows.
- **A7 — The agy context-size knob (256K/512K/900K) is out of scope** for this change; agetor has no field for it and no verified flag name.

## 7. Risks & blast radius

- **Runtime 400/404 on the gemini harness** if the user's backend/plan lacks Argon (Free tier, AI Pro plan, unconfirmed Code Assist tiers, Vertex non-`global` locations): the pre-existing verbatim-passthrough risk class, now with a model that is tier-gated unlike 3.8 Flash.
