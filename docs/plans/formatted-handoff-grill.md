# Grill — formatted handoff card in agent transcripts

| Field | Value |
| --- | --- |
| Date | 2026-10-29 |
| Source | Pipeline "Alamo Pipeline (No Video)" goal + `docs/plans/formatted-handoff-investigation.md` (step 1, "Investigation") |
| Mode | interactive, answered by the owner in three structured passes (AskUserQuestion) |
| Flags | none |

**Goal:** a pipeline step agent ends its final message with a `<handoff>{json}</handoff>` block. Today it shows as raw text: react-markdown 10 emits it as one escaped text node and the JSON collapses to one wrapped line. Instead, render it as a formatted card, with a modal for the full handoff and a quick way to open the files it references.

## Settled by evidence, not asked

- **No server, API or DB change** beyond the runner's locator, because D7 rules out a file-content route. `src/shared/pipeline.ts` imports only types, so the webview can run the shared locator and `parseHandoff` directly (investigation §1).
- **Same trust tier as today.** Handoff text is agent output that is already rendered as markdown. Artifacts open through the existing desktop-only `/open-path`, `/reveal-path` and `/open-external` routes. Nothing new reaches the filesystem.
- **Render cost is bounded.** `normalizeHandoff` caps a handoff at 64 KB. The splitter measured 0.06 ms per event on average. No per-render fetches: one cached `/refs/resolve` per card.
- **RunPanel invariants.** A modal mounted at `RunPanelBody` level needs a namespaced key (`handoff-…`) and its open-state reset in the `[task.id]` reset effect. A portaled card-local modal avoids both. The plan picks one, and either is consistent with D4.
- **Copy and quote.** `QuoteSelectionButton` quotes the rendered card text. Copy JSON (D5) covers the raw form.

## Assumptions still open

- **The code-span rules match CommonMark closely enough.** The shared locator treats backtick runs as inline code only when a closing run of equal length exists, and fences as ```` ``` ```` or `~~~` runs at line start. An unmatched backtick is literal. If it's wrong, an edge case diverges from what react-markdown shows as code. The runner and the UI still agree, because they share the locator. The plan must pin this with unit tests built from synthetic fixtures modelled on the spike's 1,484-event agreement (never real transcripts).
- **The run-generation match for D18 holds.** File names embed `run.startedAt` in base36 (since round 4). If an older file predates that naming, the lookup misses and the chip falls back to OS-open. That is graceful, not broken.
- **The frozen graph is available on every step task's panel.** The pipeline strip already fetches it. If the fetch fails (for example, the parent was deleted), the card shows `next` verbatim (D14) and no "Not used" chip (D21).
- **The 4-line clamp and the 6-chip limit are judgment values** the owner confirmed as defaults. Both are cheap to tune during review.
